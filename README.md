# SpellQuest

A first-level spelling adventure prototype for Year 5–6 children. Explore the forest, collect four letters and help the owl wake a sleeping pen by building and tracing its spell.

GitHub Pages: https://jamesuxer.github.io/spellquest/

Use arrow keys or WASD to walk. Press E / Space near a character, or use the interaction button. At the workbench, drag or select letter blocks, revise them, then trace with the pen. Keyboard users can focus the pen and hold Right Arrow, releasing between letters.

Progress saves in the current browser. Start again in the forest resets the journey. The prototype ends after receiving the pen and returning to the forest. See START-HERE.md for device checks and session setup.

This repository contains only the packaged game and test-build instructions. The build identifier is in build-info.json. Artwork and voices remain provisional; physical Chromebook and child usability checks are pending.
